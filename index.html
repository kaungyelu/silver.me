Simple process

ရှင်းလင်းတဲ့ အဆင့် ၄ ဆင့်Four clear steps

Project စတင်ချိန်ကနေ အသုံးပြုနိုင်တဲ့အချိန်အထိ သိသင့်တာတွေကို ရှင်းလင်းစွာ ဆွေးနွေးပေးပါတယ်။Clear communication from the first conversation through launch.

01

လိုအပ်ချက် ဆွေးနွေးခြင်းDiscovery

ရည်ရွယ်ချက်၊ အသုံးပြုသူနဲ့ workflow ကို နားလည်အောင် ဆွေးနွေးပါမယ်။We understand your goal, users and workflow.

02

အစီအစဉ်နဲ့ ဈေးနှုန်းScope & quote

ပါဝင်မယ့် function၊ ကြာချိန်နဲ့ ကုန်ကျစရိတ်ကို သတ်မှတ်ပါမယ်။We agree on features, timeline and cost.

03

ဖန်တီးခြင်းနဲ့ စမ်းသပ်ခြင်းBuild & test

အဆင့်လိုက် ဖန်တီးပြီး လက်တွေ့အသုံးပြုမှုကို စမ်းသပ်ပါမယ်။We build in stages and test real use cases.

04

လွှင့်တင်ခြင်းLaunch

Source code နဲ့ အသုံးပြုနည်းကို လွှဲပေးပြီး support ဆက်ပေးပါမယ်။We launch, hand over the source and support you.

FAQ

မေးလေ့ရှိသော မေးခွန်းများCommon questions

Project တစ်ခု ဘယ်လောက်ကြာပါသလဲ?How long does a project take?

Function နဲ့ scope ပေါ်မူတည်ပါတယ်။ လိုအပ်ချက်ဆွေးနွေးပြီးနောက် အဆင့်အလိုက် ကြာချိန်ကို ရှင်းလင်းစွာ ပေးပါမယ်။It depends on the scope. After discovery, you'll receive a clear stage-by-stage timeline.

Source code ရပါသလား?Will I receive the source code?

ရပါတယ်။ Project ပြီးဆုံးပြီး သတ်မှတ်ချက်များ ပြည့်စုံချိန်မှာ source code နဲ့ လိုအပ်တဲ့ မှတ်တမ်းတွေကို လွှဲပြောင်းပေးပါတယ်။Yes. The source code and essential documentation are handed over at completion.

ဈေးနှုန်း ဘယ်လိုသတ်မှတ်ပါသလဲ?How is pricing decided?

လိုအပ်တဲ့ function၊ ချိတ်ဆက်ရမယ့် service နဲ့ အလုပ်ပမာဏပေါ် အခြေခံပါတယ်။ စတင်မလုပ်ခင် quote ကို အတည်ပြုပါမယ်။Pricing is based on features, integrations and workload, and is agreed before work begins.

ရှိပြီးသား system ကို ပြင်ပေးနိုင်ပါသလား?Can you improve an existing system?

စစ်ဆေးပြီးနောက် ပြင်ဆင်ခြင်း၊ feature ထပ်ထည့်ခြင်း သို့မဟုတ် သင့်တော်တဲ့ ပြန်တည်ဆောက်မှုကို အကြံပြုပေးနိုင်ပါတယ်။After a review, we can repair it, add features or recommend a suitable rebuild.
